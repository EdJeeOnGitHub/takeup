# Structural robustness appendix modules

This directory collects the paper-facing structural robustness material that
was previously split across `temp-data/` and implementation notes.  It does
not modify `ref-reports/ECM ReStud.tex`.

Each file in `sections/` is a complete, independently compilable LaTeX file.
The `docmute` package lets a parent document include any of them with ordinary
LaTeX input, for example:

```tex
\usepackage{docmute}
\input{appendix/structural-robustness/sections/student-t-types.tex}
```

To include the entire bundle instead, use:

```tex
\usepackage{docmute}
\input{appendix/structural-robustness/structural-robustness-appendix.tex}
```

The command `\StructuralRobustnessPath` contains the bundle path.  Define it
before `\input` if the directory is moved in Overleaf or another paper repo.
The default is `appendix/structural-robustness`.

The copied tables and figures are deliberately stable paper artifacts. Their
maintained source workflows are in `scripts/appendix/` with cluster launchers
in `hpc/`; underlying numerical outputs remain in `temp-data/` or the shared
Midway analysis directory.

The randomization-inference section is regenerated with
`Rscript scripts/appendix/randomization-inference.R --permutations=99999`. It preserves
the exact four-arm counts within the original county-by-assigned-distance
randomization strata and reports original-assignment results separately from
realized-distance sensitivity analyses. Stable outputs are written first to
`ref-reports/randomization-inference/` and then copied into this bundle.

The reduced-form relative-distance-multiplier section is regenerated with
`Rscript scripts/appendix/reduced-form-distance-multiplier.R` inside the project analysis
container. It uses the canonical 9,805-person no-SMS sample, reports the
original randomized Close/Far contrast together with linear and natural-spline
continuous-distance responses, and uses 1,000 county-stratified exponential
community-weight draws. Stable outputs are first written to
`ref-reports/reduced-form-distance-multiplier/`; the table and two figures are
then copied into this appendix bundle. The analysis identifies a relative
distance response under a common direct-cost restriction, not an absolute
multiplier relative to zero observability.

The alternative-observability multiplier table is regenerated with
`Rscript scripts/appendix/summarize-struct-observability-multipliers.R`.

The two compact 1.25 km multiplier tables are rendered from a common
draw-level file with:

```bash
Rscript scripts/appendix/render-multiplier-robustness-1250.R
```

The primary input
`temp-data/assigned-distance-comparison/multiplier-draws-1250.csv` contains
exact posterior multiplier draws at the experiment's Close--Far threshold.
The renderer supplements it with the exact draws for the tight asymmetric
multinomial reporting model from
`temp-data/asymmetric-observability-comparison/multiplier-draws-1250.csv`.
That correct-classification model uses the truth-linked multinomial
Yes/No/Don't-know response channel and replaces the earlier binary
correct/incorrect structural sensitivity; binary correct classification
remains a reduced-form validation outcome. The renderer
validates the complete specification-by-arm grid, calculates the posterior
median, 95 percent interval, and probability of mitigation, and writes
custom-save-style LaTeX fragments without floats, captions, labels, or notes.
The fragments are
`tables/main-core-multiplier-robustness-1250m.tex` and
`tables/main-core-multiplier-prior-sensitivity-1250m.tex`. Within every table
cell, the three lines are the posterior median, 95 percent interval, and
`Pr(M < 1)`, respectively. Posterior probabilities are reported to three
decimal places, with values below 0.001 displayed as `<0.001` and values above
0.999 displayed as `>0.999`, matching the paper's p-value precision.

The multiplier prior-sensitivity section uses the isolated 13-specification
workflow `hpc/structural/submit_main_core_prior_grid.sh`. It varies the social-image weight,
distance cost, idiosyncratic heterogeneity, first-order visibility schedule,
and private-utility priors one module at a time, then repeats the exercise with
all modules jointly tight or diffuse. Each specification starts with four
chains of 400 warmup and 400 retained draws; specifications flagged by the
saved R-hat, effective-sample-size, divergence, or treedepth audit are rerun at
800/800 before paper use. The primary output is the finite 0--2.5 km
multiplier, four arm-specific intervals, and the paired directional posterior
probabilities. This ordinary-posterior grid is deliberately separate from the
999-draw exponential community-weight workflow. Shared results are stored in
`main-core-prior-grid/`; `scripts/appendix/summarize-main-core-prior-grid.R` writes the
CSV audit bundle and `tables/main-core-prior-grid.tex` fragment.

The finite-mixture intrinsic-motivation section is generated by the isolated
Midway3 workflow `hpc/structural/submit_main_core_finite_mixture_midway3.sh`. It estimates a
two-component Gaussian mixture whose mean and variance are normalized to the
baseline values, runs four parallel chains with 800 warmup and 800 retained
draws each, and then evaluates only the compact generated quantities used by
the appendix. `scripts/appendix/summarize-main-core-finite-mixture.R` produces the
multiplier table, fit and mixture-shape summaries, and the posterior density
figure. The shared analysis output is stored under
`main-core-finite-mixture-robustness-800/`. The Midway3 runner requires
CmdStanR 0.9.0 or newer when used with CmdStan 2.35; older CmdStanR releases
misread the completed CSV metadata even though Stan has written all draws.

The campaign-day reduced-form section is regenerated with
`Rscript scripts/appendix/campaign-day-original-assignment.R`. It uses the original
randomized Close/Far assignment, directly recorded take-up dates, and paired
exponential cluster weights. The script writes its full review bundle to
`ref-reports/campaign-day/` and synchronizes the paper-facing tables and figures
into this appendix. The analysis deliberately does not use IV or conditional
post-treatment risk sets.

The tighter-prior asymmetric-reporting table is generated from
`scripts/appendix/summarize-main-core-report-distance-priors.R`; its underlying draws
and summaries are stored in the shared Midway analysis directory under
`main-core-report-distance-priors/`. The same workflow now includes the
unrestricted, hierarchical, tighter-prior, and design-pooled specifications
and generates the covariance-aware No Signal--Any Signal contrast table. The
design-pooled GQ outputs use the isolated `design-pooled/gq-newton/`
directory so the retained-draw audit is not contaminated by older binaries.
The Newton-first solver is used for multiplier objects: it reproduces the
original multiplier values exactly wherever the original algebra solver
returned a value and supplies finite values for the remaining draws. Because
alternative roots can change some counterfactual take-up levels, the summary
script deliberately continues to take design-pooled ATEs from the original
`design-pooled/gq/` outputs rather than using the fallback solver to strengthen
ATE claims.

The preferred cluster adjustment uses 999 sets of exponential community
weights from the `main-core-exponential-cluster-weight-999/` workflow. Raw weights are
normalized within county, producing a stratified Dirichlet weighting scheme.
The summary code applies each community's weight to every likelihood block,
leaves priors unweighted, and reports percentile intervals across weighted
posterior modes.
`scripts/appendix/summarize-main-core-cluster-robustness.R` generates the multiplier
table and paired contrasts;
`scripts/appendix/generate-main-core-cluster-bootstrap-ate-table.R --method=exponential`
generates the structural treatment-effect table; and
`scripts/appendix/generate-main-core-finite-segment-multiplier-table.R` generates the
finite 0--2.5 km, 0--1.5 km, and 1.5--2.5 km multiplier table. Conventional multinomial
resampling outputs remain archived as an internal sensitivity check but are
not part of this paper-facing appendix.
`hpc/structural/submit_main_core_cluster_bootstrap_999.sh` is the portable Midway2/Midway3
entry point for this run. All 999 attempted refits completed with distinct
weight vectors; the stable paper tables and local summaries use those refits.

The policy-model robustness tables are regenerated with
`Rscript scripts/policy/assemble-model-robustness.R`. The concise contrast table
is the paper-facing summary; the full table preserves the policy-level
diagnostics for every model and counterfactual.

The policy distance-cap diagnostic is regenerated locally with
`Rscript scripts/policy/generate-distance-cap-table.R`. It documents why a
2.5 km cap nearly reproduces the experimental cluster-separation constraint
and therefore cannot identify meaningful consolidation differences. The local
appendix retains 3.5 km as the maintained cap and reports the 2.5--3.5 km
feasibility gradient transparently. This module is not input by
`ref-reports/ECM ReStud.tex`.

Policy geography is built in the explicit `--all-pots` mode of
`scripts/policy/create-distance-data.R`. The canonical object contains all 1,451
documented candidate schools; the older 1,092-site object resulted from a
row-index/`cluster.id` mismatch in the sampled-site path and is not used for
the local appendix results.

The population-weighted allocation and break-even calculations are generated
with `scripts/policy/run-population-cost.R`. Baseline posterior draws use
`--parameter-type=raw`; the preferred exponential cluster-weighted modes use
the canonical parameter CSV produced by
`scripts/policy/prepare-cluster-bootstrap.R` and `--parameter-type=canonical`.
`scripts/policy/assemble-population-cost.R` combines every available inference
set into the appendix tables and break-even figure. Signal and travel costs
are resource-cost scenarios applied to coverage-preserving allocations, not a
Ramsey welfare calculation. The same runner also reports a prespecified
pooling sensitivity in which Bracelet observability for assignments away from
the experimental PoT moves 0, 50, or 100 percent toward Control observability.
This is a conservative proxy for information dilution under consolidation,
not an endogenous model of site traffic.

`scripts/policy/predict-cluster-bootstrap.R` stores policy demand as a numeric
draw-by-edge matrix plus a two-column draw map. The compact representation was
checked element-for-element and allocation-for-allocation against the older
long data-frame representation; it is roughly fourteen times smaller in the
three-draw production smoke test.

Local baseline reproduction is:

```bash
Rscript scripts/policy/generate-distance-cap-table.R
Rscript scripts/policy/run-population-cost.R \
  --analysis-id=baseline-posterior --parameter-type=raw --cores=8
Rscript scripts/policy/assemble-population-cost.R
Rscript scripts/policy/validate-population-cost.R
```

When the exponential-mode parameter CSV is available, use the same runner
with `--parameter-type=canonical
--analysis-id=exponential-cluster-weights`; no separate policy implementation
is required.

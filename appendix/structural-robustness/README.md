# Structural robustness appendix modules

This directory collects the paper-facing structural robustness material that
was previously split across `temp-data/` and implementation notes.  It does
not modify `ref-reports/ECM ReStud.tex`.

Each file in `sections/` is a complete, independently compilable LaTeX file.
The `docmute` package lets a parent document include any of them with ordinary
LaTeX input, for example:

```tex
\usepackage{docmute}
\input{appendix/structural-robustness/sections/student-t-types.tex}
```

To include the entire bundle instead, use:

```tex
\usepackage{docmute}
\input{appendix/structural-robustness/structural-robustness-appendix.tex}
```

The command `\StructuralRobustnessPath` contains the bundle path.  Define it
before `\input` if the directory is moved in Overleaf or another paper repo.
The default is `appendix/structural-robustness`.

The copied tables and figures are deliberately stable paper artifacts.  Their
source workflows remain in `scratch/`, and the underlying numerical outputs
remain in `temp-data/` or the shared Midway analysis directory.

The alternative-observability multiplier table is regenerated with
`Rscript scratch/summarize-struct-observability-multipliers.R`.

The tighter-prior asymmetric-reporting table is generated from
`scratch/summarize-main-core-report-distance-priors.R`; its underlying draws
and summaries are stored in the shared Midway analysis directory under
`main-core-report-distance-priors/`. The same workflow now includes the
unrestricted, hierarchical, tighter-prior, and design-pooled specifications
and generates the covariance-aware No Signal--Any Signal contrast table. The
design-pooled GQ outputs use the isolated `design-pooled/gq-newton/`
directory so the retained-draw audit is not contaminated by older binaries.

The primary cluster-bootstrap artifacts are generated by
`submit_main_core_cluster_bootstrap_999.sh` and stored under the shared Midway
roots `main-core-cluster-bootstrap-999/` and
`main-core-cluster-bootstrap-999-results/`. The latter contains an explicit
attempted/successful/included audit, hashes for all resampling-weight vectors,
the structural ATE table, and the paired multiplier-contrast table. The
scheduler submission is split into self-chaining batches only to respect
Midway's submitted-job cap; it still comprises one prespecified set of 999
county-stratified refits.

The policy-model robustness tables are regenerated with
`Rscript optim/assemble-policy-model-robustness.R`. The concise contrast table
is the paper-facing summary; the full table preserves the policy-level
diagnostics for every model and counterfactual.

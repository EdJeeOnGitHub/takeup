## Baseline

What we said in the PAP:

"From each cluster a random sample of 15 censused HHs were selected and from each HH one adult randomly selected."

PAP N      = 2,160 = 15*144
Reality:
Selected N = 2,160
Reached  N = 2,062
Complete N = 1,995


## Endline

"From each cluster we randomly picked 25 individuals for an endline survey."

PAP N = 3,600 = 25*144

Reality:
Selected N = 4,220
Reached  N = 3,830 
Complete N = 3,729

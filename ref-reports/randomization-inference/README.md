# Randomization inference for reduced-form interactions

This module reproduces the four-arm community randomization and evaluates the
treatment-by-distance interactions for administrative take-up and three measures
of observability.

## Design

Control, Calendar, Ink, and Bracelet are reallocated within county × finalized
Close/Far strata. Every permutation preserves the observed arm counts within each
of the six strata. Original assigned distance, finalized binary distance, and
continuous realized distance are held fixed. Consequently, the latter two panels
are conditional treatment-randomization tests—not tests generated by permuting
realized distance.

The primary estimands use original assigned Close/Far status. Finalized Close/Far
and realized kilometers are a separate sensitivity family. Take-up and
observability are also separate multiplicity families.

## Run

Smoke test:

```sh
Rscript scripts/appendix/randomization-inference.R \
  --permutations=999 \
  --output-dir=/tmp/takeup-ri-smoke \
  --appendix-dir=/tmp/takeup-ri-appendix
```

Production:

```sh
Rscript scripts/appendix/randomization-inference.R --permutations=99999 --cores=4
```

The fixed default seed is `20260812`. The runner uses base R and community-level
sufficient statistics. It therefore exactly targets the individual-level OLS
regression while avoiding 99,999 repeated fits to the 9,805-row dataset.

## Outputs

- `data/ri-results.csv`: estimates, clustered intervals, Fisher and studentized
  RI p-values, Romano–Wolf p-values, and Monte Carlo standard errors.
- `data/ri-omnibus-results.csv`: omnibus equality-of-gradients tests.
- `data/assignment-stratum-counts.csv`: assignment-mechanism audit.
- `data/sample-audit.csv` and `data/permutation-audit.csv`: sample and run audit.
- `tables/randomization-inference.tex`: input-ready table.
- `figures/`: community-level take-up diagnostics.
- `randomization-inference-note.tex` and PDF: standalone review copy.

The local appendix copy is `appendix/structural-robustness/sections/randomization-inference.tex`.
No Overleaf manuscript files are changed by this module.
